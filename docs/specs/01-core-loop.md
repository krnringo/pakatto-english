# 01. コアループ(パック開封・カード図鑑・復習)

## Outcomes(目的)

3〜6歳の子どもが親と一緒に、スタミナ制でパックを開封して英単語カードを集め、
図鑑で眺めて音声を聞き返せる状態。重複カードは「復習」として明示され、
カードごとの所持枚数・復習回数が記録される(ポケポケ型の収集体験)。

## Scope boundaries(範囲)

### やること
- パック選択・開封画面(スタミナ制、縦スワイプ選択、タップでめくる演出)
- カード図鑑(パック別タブ、シルエット、拡大+音声、進捗・枚数・復習回数表示)
- 復習判定ロジック(重複=復習の記録と演出)
- パックコンプリート演出
- 親向け簡易進捗画面(収集数・復習回数の極簡表示)
- ローカルデータ永続化

### やらないこと(次フェーズ送り)
- クイズ形式の能動的復習(v1は受動接触のみ)
- iCloud同期・アカウント機能(データはローカルのみ。機種変更でリセットは許容)
- 親向けの詳細な学習分析画面(グラフ・履歴等)
- 広告(v1は広告なし)
- Android対応
- サブスク課金の実装そのもの(RevenueCat導入は別仕様書で扱う。本仕様では
  「パックが解放済みかどうか」のフラグがある前提でのみ設計する)

## Constraints(制約)

- 対象は3〜6歳(未就学児)。**文字が読めない前提**: UIは絵・アイコン・音声中心。
  文字は英単語表記(カード上)と親向け画面のみ
- 親と一緒に操作する前提だが、子どもが一人でタップしても課金・外部リンクに
  到達しないこと(課金導線・外部リンクはペアレンタルゲート必須 — 別仕様)
- Kids Category審査対応: トラッキングなし・データ収集は端末内のみ
- Flutter / iOS のみ(v1)
- 絵はAI生成イラスト、音声はAI TTS(ネイティブ英語)。1ヶ月の制作期間に収める
- 時刻はデバイス時刻を使用(スタミナ回復判定)。時刻改ざんによるスタミナ回復は
  v1では対策しない(子ども向けアプリで実害が小さいため)

## Prior decisions(既存の決定事項)

蒸し返さない(出典: 壁打ち要件定義 2026-07-09):

- 初回3パック: 無料=いろ(Colors)/有料=どうぶつ(Animals)+のりもの(Vehicles)。各10〜15語
- 収益化はサブスク(RevenueCat)。無料パックは永久無料
- 公開目標 2026-08-08頃。撤退基準: 公開後3ヶ月でサブスク登録20人未満
- 本仕様書のインタビューでの決定:
  - **スタミナ制**: 回復4時間/1回、最大ストック2回分。開封1回=スタミナ1消費
  - **1回の開封で3枚**(パック内全語から完全ランダム・均等抽選、重複あり)
  - **コンプリート後も開封継続可能**(全カードが復習になる)
  - **重複カードは新規と見た目で区別**(復習バッジ演出)
  - **カードごとに所持枚数・復習回数を記録**し図鑑で見える
  - **復習は受動接触のみ**(正誤判定・クイズなし)
  - **開封演出**(2026-07-10 更新 v2: 二段階選択+ビジュアル/音声の強化):
    1. ホーム=**パック(ライン)選択**。解放済みのパック種(Colors/Animals/Vehicles)が
       横カルーセルで並び、横スワイプでぐるぐる回転して選ぶ
    2. 中央のパック種を**タップ**すると、**同じパック種の未開封の袋が縦に何個も
       並ぶカルーセル画面**(パック袋選択画面)に遷移する。縦スワイプでぐるぐる
       回して好きな袋を選ぶ(袋はすべて中身が同じ抽選対象で見た目は同一。
       在庫概念はなく、スタミナがある限り何個でも選べる「見せかけの複数化」)
    3. 選んだ袋を**タップすると開封**(既存の抽選・永続化ロジックへ)→開封演出
       (弾ける)→3枚のカードが**重なって**出る→上のカードをタップで1枚ずつめくる
       (めくると音声再生+新規/復習バッジ、もう一度タップでどかして次の1枚)
    (2026-07-10 v1の「横カルーセルで中央パックをそのままタップ開封」から変更。
    ポケポケは「エキスパンションを選ぶ→複数のパック袋から1つ選ぶ→開封」の
    二段階なので、それに合わせた)
  - **ビジュアル**(2026-07-10 追加): パック袋は薄っぺらい単色カードでなく、
    光沢グラデーション+上部の折り返し(襟)+エンブレムバッジ+斜めに流れる
    ホロの光沢(shimmerアニメーション)で「安っぽく見えない」処理をする。
    カード裏面・表面にも同様にグロス感(光沢ハイライト・二重枠)を付ける。
    実アセット(AI生成イラスト)投入までのプレースホルダ品質を底上げする目的
  - **音声**(2026-07-10 追加): OS内蔵TTSのパラメータ(pitch/rate)を上げて
    子ども向けのテンション高い読み上げにする。単語そのものは変えず、末尾に
    「!」を付けて弾んだイントネーションを誘発する。本格的な元気な声(実収録
    のキッズ向けVA)はタスク8のAI音声差し替えで対応する
  - **図鑑**: パック別タブ(未購入パックのタブも表示=購入導線)、未収集は
    シルエット表示、タップで拡大+音声再生、進捗表示(例: 8/12)
  - **親向け簡易進捗画面をv1に含める**(極簡: パック別収集数・総復習回数程度)
  - **データはローカル保存のみ**

## 画面・ロジック仕様

### 1. データモデル

- `Card`: id / 英単語 / パックid / イラストアセットパス / 音声アセットパス
- `Pack`: id / 名前(表示は絵アイコン) / カードリスト / 無料or有料フラグ
- `OwnedCard`(永続化): cardId / 所持枚数 / 復習回数(2枚目以降を引いた回数) /
  初回取得日時
- `StaminaState`(永続化): 現在スタミナ(0〜2) / 最終消費日時
  - 回復計算: 起動時・画面表示時に `(now - 最終消費日時) / 4h` を加算、上限2でクランプ
- パックのマスタデータ(単語リスト)はアプリ内バンドル(JSONまたはDartコード)。
  サーバー不要

### 2. パック開封画面

- ホーム=**パック(ライン)選択画面**。解放済みのパック種が横カルーセルで並ぶ
- スタミナ表示(例: ⚡2/2)。スタミナ0のときはパックがグレーアウトし、
  タップすると「次の回復までの残り時間」を絵的に表示(文字最小限)
- **横スワイプでパックがぐるぐる回転**して選ぶ(中央=選択中)。左右のパックを
  タップするとそのパックが中央に回ってくる
- 中央のパック種を**タップ**すると**パック袋選択画面**に遷移する
  - 同じパック種の未開封の袋が**縦カルーセル**で何個も並ぶ(見せかけの複数化。
    実際は在庫でなくスタミナ制御)。**縦スワイプでぐるぐる回転**して選ぶ
  - 中央の袋を**タップで開封** → 開封アニメーション
- カード3枚が**重なって**裏向きで出る → 上の1枚をタップでめくる
  - めくった瞬間: イラスト表示+英単語TTS音声再生+新規/復習バッジ
  - もう一度タップするとその1枚がどかされ、次の1枚が上に来る(1枚ずつオープン)
  - **新規カード**: キラキラ等の「はじめて!」演出
  - **重複カード**: 「もういちど!」の復習バッジ演出(新規と明確に区別)+
    所持枚数カウントアップ表示(例: ×3)
- 3枚めくり終えたら結果の導線(図鑑 or ホームへ)
- このパックがコンプリート(全種収集)に到達した開封では、コンプリート演出を挟む

### 3. カード図鑑画面

- 上部タブでパック切替(Colors / Animals / Vehicles)。未購入パックのタブも
  表示し、開くとシルエット一覧+購入導線(ペアレンタルゲート越し — ゲート実装
  自体は別仕様)
- 各タブ: カードグリッド(10〜15枚)+進捗表示(例: 8/12、コンプリートで王冠等)
- 収集済みカード: イラスト表示+所持枚数バッジ(例: ×3)
- 未収集カード: シルエット(影絵)表示。タップしても音声は出ない
- 収集済みカードをタップ → 拡大表示+音声再生。拡大ビューに所持枚数・
  復習回数を表示。再タップでもう一度音声再生

### 4. 復習判定ロジック

- 抽選: パック内全カードから均等ランダム(所持状況で重み付けしない)
- 判定: 引いたカードの所持枚数が1以上なら「復習」
  - `OwnedCard.復習回数 += 1`、`所持枚数 += 1`
  - 開封演出で復習バッジを表示
- 新規なら `OwnedCard` を作成(所持枚数=1、復習回数=0)

### 5. 親向け簡易進捗画面

- 入口はホーム隅の控えめなボタン(子ども向け動線から分離)
- 表示内容(v1はこれだけ): パック別の収集数(8/12形式)、総開封回数、総復習回数
- 詳細分析・グラフは次フェーズ

## Task breakdown(タスク分解)

検証可能な単位で切る。一番自信がない開封演出まわりを先に潰す:

1. **Flutterプロジェクト作成+マスタデータ**: プロジェクト雛形、Colorsパック
   10語分のマスタデータ(仮アセット: プレースホルダ画像+仮音声)を定義し、
   一覧をデバッグ表示して確認
2. **開封演出のプロトタイプ**(最リスク): パック浮遊→縦スワイプ開封→3枚
   タップめくり→音声再生、を仮アセットで動かし実機で体感確認
3. **抽選+復習判定+永続化**: 抽選ロジックと OwnedCard/Stamina の永続化を
   実装し、ユニットテストで確認
4. **スタミナ制**: 消費・時間回復・上限2・0時のグレーアウト表示。時刻を
   モックしたユニットテスト+実機確認
5. **図鑑画面**: タブ・グリッド・シルエット・拡大+音声・進捗/枚数/復習回数
   表示。画面で確認
6. **演出の仕上げ**: 新規/復習バッジ・コンプリート演出。画面で確認
7. **親向け簡易進捗画面**: 集計表示。画面で確認
8. **実アセット差し替え**: AI生成イラスト+TTS音声をColorsパック分投入して通し確認

## Verification criteria(検証基準)

### ユニットテスト
- 抽選: 10語パックで1000回抽選し、全カードが出現し偏りが極端でないこと
- 復習判定: 所持0のカードを引く→枚数1/復習0。同カードを再度引く→枚数2/復習1
- スタミナ: 2/2で1回開封→1/2。最終消費から4時間経過で+1、8時間で+2、
  12時間放置でも2(上限クランプ)。スタミナ0で開封APIを呼ぶとエラー/拒否
- 進捗: 10語中7種所持で「7/10」、10種で コンプリートフラグtrue

### 画面確認(実機)
- パック種が横スワイプで回転して選べる→中央パック種をタップ→袋が縦カルーセルで
  並ぶ画面に遷移→縦スワイプで回転して袋を選ぶ→中央の袋をタップで開封→重なった
  3枚を1枚ずつタップでめくる(めくる→どかす→次)→各めくりで音声が鳴る、が
  通しで動く
- 重複カードで「もういちど!」バッジ、新規カードで新規演出が出て見分けられる
- コンプリート到達開封でコンプリート演出が出る
- 図鑑: 未収集がシルエット、収集済みタップで拡大+音声、枚数×N・復習回数表示
- スタミナ0でパックがグレーアウトし開封できない、時間経過(または時刻変更)で復活
- アプリ強制終了→再起動で収集状況・スタミナが保持されている
- 親向け画面にパック別収集数・総開封回数・総復習回数が表示される
